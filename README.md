# 哔哩哔哩浏览器扩展合集

三个互相独立的 B 站（哔哩哔哩）浏览器扩展，用原生 JavaScript 写成，Manifest V3，可在 Edge、Chrome 等 Chromium 内核浏览器中直接「加载解压缩的扩展」使用。装哪个、装几个都可以，彼此不依赖。

| 扩展 | 作用 | 目录 |
| --- | --- | --- |
| **B站倍速增强** | 在播放器原生倍速菜单里增加 2.5x、3x、4x、4.5x、5x 档位 | [`bilibili-extra-speed/`](./bilibili-extra-speed) |
| **B站收藏夹纯净听歌** | 把某个标签页变成听歌专属页：自动开播、从 00:00 播放、随机切歌，不跳到合集 | [`bilibili-fav-music/`](./bilibili-fav-music) |
| **B站首页纯净视频过滤** | 首页推荐流只保留普通 UP 主投稿视频，过滤直播、纪录片、番剧、漫画、广告等 | [`bilibili-pure-video-feed/`](./bilibili-pure-video-feed) |

---

## 安装

不需要从商店安装，也不需要构建：

1. 下载本仓库（`Code` → `Download ZIP`，或 `git clone`）并解压。
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择**某一个插件所在的文件夹**，例如 `bilibili-extra-speed`。
5. 想用几个就重复第 4 步几次，每个插件单独加载一次。
6. 建议点击地址栏右侧的拼图图标，把插件固定到工具栏，方便查看面板。

> 插件没有后台服务器，也不需要安装依赖。修改代码后，在扩展管理页点一下该插件卡片上的「重新加载」，再刷新 B 站页面即可。

## 三个插件分别做什么

### 1. B站倍速增强 — `bilibili-extra-speed`

在 B 站播放器自带的倍速菜单中追加 **2.5x / 3x / 4x / 4.5x / 5x** 五档，菜单样式、位置和全屏行为全部沿用原生播放器，不会额外浮出一个面板。档位可以在 `content.js` 顶部的 `EXTRA_RATES` 常量里自己改。

如果装了 Global Speed 之类的全局倍速扩展，它会持续覆盖 B 站菜单选中的速度，需要在 Global Speed 里为 `https://www.bilibili.com/*` 加一条 Off 规则。详见 [该目录的 README](./bilibili-extra-speed/README.md)。

### 2. B站收藏夹纯净听歌 — `bilibili-fav-music`

用收藏夹当歌单听歌时常见的两个问题：B 站会顺着 UP 主的合集往下播你没收藏的视频；多个标签页的自动播放互相干扰。这个插件只接管**你指定的那一个标签页**：

- 面板里点「🎵 设为听歌专属页」，该标签页自动开播，播完自动切下一首。
- 默认**随机播放**（洗牌队列 + `crypto.getRandomValues`），也可切换顺序循环、单曲循环。
- 每个视频**从 00:00 开始**，B 站记忆的“上次看到哪”会被自动拉回开头；你自己拖进度条则不受影响。
- 多段视频默认只播 **P1**，可在面板里展开 `分P` 勾选想听的分段，未勾选的分段不会播。
- **不修改** B 站的「自动开播」「自动连播」全局开关，**不影响**其他任何 B 站标签页；关掉听歌页即恢复原样。

插件不内置任何账号信息，运行时通过 B 站接口读取当前浏览器登录账号的收藏夹，所以**使用前需要先在浏览器里登录 bilibili.com**。详见 [该目录的 README](./bilibili-fav-music/README.md)。

### 3. B站首页纯净视频过滤 — `bilibili-pure-video-feed`

首页推荐流里混杂着直播、纪录片、影视剧、番剧、漫画、课堂、专栏和商业推广卡片，这个插件只留普通 UP 主投稿视频（`/video/BV...`）：

- 按分类过滤：直播、纪录片/影视/综艺、动漫/番剧/漫画、叠层特殊卡片/课堂/专栏、广告推广。
- 兜底规则「严格只留普通投稿视频」：没有 `/video/BV...` 和 UP 主空间链接的卡片一律隐藏。
- 隐藏的是网格最外层格子，后面的正常视频会自动补位，不留空白窟窿。
- 面板可实时开关每个分类，勾选后立即生效，无需刷新页面；还能看到当前页拦截了多少个卡片。

详见 [该目录的 README](./bilibili-pure-video-feed/README.md)。

## 兼容性与注意事项

- 目标浏览器：Microsoft Edge、Google Chrome 等 Chromium 内核浏览器（Manifest V3）。
- 只匹配 `https://www.bilibili.com/*`（听歌插件只注入视频页和列表页），不访问其他网站。
- B 站前端改版后，首页卡片的类名或播放器结构可能变化，个别过滤规则可能需要跟着调整；欢迎提 Issue。
- 三个插件都只在本机运行，**不联网上传数据、不收集任何信息**。
- 本项目是非官方的个人工具，与哔哩哔哩官方无关；请自行遵守网站的服务条款，勿用于商业用途。
