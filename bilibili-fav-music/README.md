# B站收藏夹纯净听歌

把某个标签页变成「听歌专属页」，用 B 站收藏夹当歌单：自动开播、始终从 00:00 开始、播完自动随机切下一首，并且**不会顺着 UP 主的合集跑偏**。

---

## 功能

- **不乱跳合集 / 不乱播未勾选的分P**
  - 切歌完全按收藏夹里的歌单走，绝不顺着 UP 主的视频合集去播你没收藏的视频。
  - 多段视频（分P）默认只播 **P1**；可以在歌单里点开 `分P` 按钮，勾选真正想听的那几段，未勾选的分段永远跳过。
- **每个视频都从 00:00 开始**
  - B 站会把上次看到的位置记下来，插件在听歌页里检测到这种“续播”会自动拉回开头。
  - 你自己手动拖进度条、按左右方向键跳转会被尊重，不会再被拉回去。
- **只影响一个标签页，不动 B 站全局设置**
  - 不改 B 站的「自动开播」「自动连播」开关，也不干预其他任何 B 站标签页。
  - 只有被设为「听歌专属页」的那 1 个标签页会自动开播、自动切歌。
- **播放模式**
  - 默认「随机」：用洗牌队列 + `crypto.getRandomValues`，一轮内不重复。
  - 可切换「顺序循环」「单曲循环」。
  - 面板里有上一首 / 播放暂停 / 下一首，听歌页左下角也有迷你控制条。
- **其他**
  - 支持切换收藏夹、同步最新歌单、搜索歌名或 UP 主、临时跳过某首歌（不改动 B 站收藏）。

---

## 安装（Edge / Chrome）

1. 下载本仓库，解压得到 `bilibili-fav-music` 文件夹。
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择 `bilibili-fav-music` 文件夹。
5. 建议点击地址栏右侧的拼图图标，把「B站收藏夹纯净听歌」固定到工具栏。

---

## 使用

1. **登录 B 站**：插件不内置任何账号，启动后通过 B 站接口读取当前浏览器登录账号的收藏夹。没登录时面板会提示先登录。
2. **开启听歌模式**：在任意标签页点插件图标，点顶部「🎵 设为听歌专属页」，或直接点歌单里的任意一首歌。当前标签页会变成听歌专属页，左下角出现 `听歌专属页 · 🔀 随机播放 | 下一首 ⏭` 的小标识。
3. **多段视频**：带多段的视频右侧显示蓝色 `分P (n/总数P) ▾`，展开后勾选要加入歌单的分段即可，选择会自动保存。
4. **退出**：关闭该标签页，或在面板里点「关闭听歌模式」。

> 修改收藏夹后，点面板里的「🔄 同步」拉取最新列表。

---

## 权限与隐私

- 权限：`storage`（保存歌单设置）、`tabs`（把指定的听歌标签页导航到下一首）、`https://*.bilibili.com/*`（读取收藏夹、播放视频）。
- 不收集、不上传任何数据，所有状态都只存在本机的扩展存储里。
- 代码中**没有**硬编码任何人的 UID 或收藏夹 ID，都是运行时读取当前登录账号。
