# B站首页纯净视频过滤（Edge 扩展）

专门过滤 B 站首页推荐流（`https://www.bilibili.com/`）里混杂的各类非普通投稿内容，**只保留普通 UP 主正常投稿的视频（`/video/BV...`）**，并在过滤后让网格自动往前补位，不留空白窟窿。

---

## 默认过滤的内容（可在右上角插件面板随时单独开关）

1. **🎥 直播推荐**：左上角带 `直播` 角标、标题带 `直播中`、指向 `live.bilibili.com` 的直播卡片。
2. **🐳 纪录片 / 电影 / 电视剧 / 综艺**：带 `纪录片`、`电视剧`、`电影`、`综艺` 角标或指向 `/bangumi/play/...` 的剧集卡（如《进化》等）。
3. **🌸 动漫 / 番剧 / 国创 / 漫画**：带 `番剧`、`国创`、`漫画` 角标或指向 `manga.bilibili.com` 的卡片（如《排球少年!!》等）。
4. **🗂️ 特殊叠层卡片 / 课堂 / 专栏 / 活动**：底下带多层白底叠放阴影的频道推流卡（`.floor-single-card`，如剧集推荐《切尔诺贝利》等）、课堂、专栏与活动卡。
5. **🛡️ 商业广告与推广**：带 `广告`、`创作推广` 标识的推广卡片。
6. **✨ 严格只留普通投稿视频**：兜底规则，凡是没有 `/video/BV...` 链接或没有 UP 主个人空间链接的异常推流卡一律隐藏。
7. **🖼️ 隐藏左上角大图轮播（可选，默认关闭）**：如果你连首页左上角的大横幅轮播图也不想看，可以在面板里一键勾选隐藏。

---

## 安装到 Edge 浏览器

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions/` 并回车。
2. 打开 **「开发人员模式」**。
3. 点击 **「加载解压缩的扩展」**，选择本仓库中的 `bilibili-pure-video-feed` 文件夹。
4. 打开或刷新 B 站首页，所有纪录片、直播、漫画、番剧、广告都会自动消失，点击右上角插件图标还能实时看到当前页帮你拦截了多少个卡片，并随时开关任意分类（无需刷新页面，勾选即刻生效）。
